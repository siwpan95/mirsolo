# 借鉴记账

> 原则（来自全哥的创新三原则）：**借鉴必记账（来源 + 许可证 + 范围）**、
> 调整必同步（远端 / 引用 / 黄金值）、推倒重来只用于结构层。
>
> 本项目为 MIT 发布，因此**任何 GPL / AGPL 代码一律零复用**；
> 原版素材与商标一律不用。下表逐项记账，新增借鉴必须在此登记后才落代码。

## 一、代码与实现参照

| 对象 | 地址 | 许可证 | 借鉴范围 | 明确禁区 |
|---|---|---|---|---|
| Suprcode/Crystal | github.com/Suprcode/Crystal | GPL-2.0 | **仅系统结构与行为观察**：服务端由哪些子系统构成（战斗/掉落/刷新/交易/行会）、配置如何组织 | 代码一行不抄；不引入其子模块；不复制其 SQL/DB 结构 |
| Crystal.Database（资源包） | github.com/Suprcode/Crystal.Database | 素材版权归 Wemade / Actoz | 无（不下载） | 贴图 `.Lib`、地图 `.map`、音效 `.wav`、NPC 文本全部不用 |
| Zombieliu/mir2 | github.com/Zombieliu/mir2 | AGPL-3.0 | 仅阅读其"1:1 对齐路线图"文档，了解原版系统覆盖面 | 代码与资源均不复用（AGPL 传染性更强） |
| nicelnicel/Legend-of-Mir2 | github.com/nicelnicel/Legend-of-Mir2 | GPL-3.0 | 无 | 不复用 |

**清洁室做法**：只读文档与公开行为描述，不读源码逐行对照实现；
本项目所有模块均为独立设计与编码，公式常数集中在
`mirsolo/combat/formulas.py` 顶部并在 `docs/数据口径.md` 标注为近似。
